# Originais de mídia

Destino canônico para novos arquivos visuais recebidos sem tratamento quando não houver uma categoria mais específica.

- não sobrescrever arquivos de origem;
- preservar nome, data e metadados úteis para rastreabilidade;
- ativos específicos da CookLily pertencem a `mídias/cooklily/`;
- derivados de produtos do Carro Chefe pertencem a `mídias/produtos/<produto>/`;
- o acervo histórico em `mídias/files/` permanece somente por compatibilidade e não deve receber novos conjuntos.

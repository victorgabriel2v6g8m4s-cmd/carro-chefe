# Originais de mídia

Destino canônico para novos arquivos visuais recebidos sem tratamento.

- não sobrescrever arquivos de origem;
- preservar nome/data/metadados úteis para rastreabilidade;
- derivados devem ir para a categoria apropriada, preferencialmente `mídias/produtos/<produto>/derivados/` ou outra pasta temática documentada;
- o acervo histórico em `mídias/files/` permanece somente por compatibilidade com manifests e referências existentes e não deve receber novos arquivos.

# Chefinho — documentação de referência para IA

## Contexto

Esta pasta reúne 13 fotografias JPEG do produto **Chefinho**, importadas como originais de referência.

## Uso documental sem abrir todas as imagens

Uma IA pode usar esta pasta e o `MEDIA_MANIFEST.json` para saber que existe um conjunto fotográfico dedicado ao Chefinho, localizar arquivos, verificar dimensões, hashes, quantidade e selecionar candidatos por orientação antes de uma análise visual.

## Usos potenciais

Após inspeção visual individual, as imagens podem servir para: capa do produto no site, cardápio, Instagram, stories, criativos de anúncio, totem digital, comparativos entre tamanhos/produtos e referência de montagem para equipe ou geração de imagens.

## Edição

Como os arquivos são registros brutos, não presumir que estejam prontos para publicação. Antes de uso final, avaliar exposição, cor, nitidez, enquadramento, sujeira/reflexos no fundo, fidelidade da montagem e espaço disponível para texto/CTA. Qualquer tratamento deve ser salvo como derivado, preservando o original.

## Utilidade

O conjunto deve ser tratado como **acervo de referência com revisão pendente**. A sequência de arquivos em poucos segundos sugere possíveis ângulos parecidos; redundância deve ser determinada visualmente, não apenas pelo nome.

## REGRA OBRIGATÓRIA PARA IA

Para inventário e contexto, basta esta documentação. **Para classificar qualidade, dizer que uma foto é boa/ruim/inútil, escolher imagem final, editar, recortar ou publicar, a IA DEVE abrir os JPEGs candidatos antes da decisão.**

Metadados técnicos ficam em `../MEDIA_MANIFEST.json`.

# Pimentas — documentação de referência para IA

## Contexto

Esta pasta reúne 2 fotografias JPEG relacionadas a **pimentas / insumo** do projeto Carro Chefe.

## Uso sem inspeção visual

Uma IA pode usar esta documentação e o `MEDIA_MANIFEST.json` para localizar os arquivos, saber que representam o insumo pimenta e consultar dimensões, tamanho e hashes sem precisar abrir as duas fotos em tarefas simples de busca ou inventário.

## Usos potenciais após inspeção visual

- comunicação de ingredientes/picância;
- post educativo ou promocional no Instagram;
- stories;
- cardápio, quando houver indicação de nível de picância ou ingrediente;
- material interno de referência de insumo;
- composição secundária em peças de produto, desde que a foto seja tecnicamente adequada.

## Edição

Antes de uso público, verificar fundo, cor, nitidez, identificação correta da variedade, escala, aparência do alimento e se a imagem é representativa do ingrediente realmente usado na operação. Tratamentos devem gerar derivados, preservando o original.

## Utilidade

Com apenas duas imagens, nenhuma deve ser descartada sem inspeção. Elas podem cumprir funções diferentes (registro de insumo, detalhe, composição etc.).

## REGRA OBRIGATÓRIA PARA IA

Para inventário e contexto, este README basta. **Para identificar visualmente a variedade, avaliar qualidade, editar, recortar, escolher para peça final ou fazer qualquer afirmação visual específica, a IA DEVE abrir a imagem correspondente.**

Metadados técnicos ficam em `../MEDIA_MANIFEST.json`.

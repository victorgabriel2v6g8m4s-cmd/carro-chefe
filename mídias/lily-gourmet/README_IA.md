# Lily Gourmet — leitura rápida do acervo por IA

Este arquivo resume como agentes devem usar o acervo em `mídias/lily-gourmet/`.

## Pode usar a documentação sem abrir o arquivo para

- localizar a logo, o adesivo e as fotos;
- obter IDs, nomes esperados, dimensões e hashes já conferidos;
- entender preliminarmente o conteúdo visual;
- selecionar candidatos para uma tarefa futura;
- saber quais arquivos exigem revisão ou reenvio.

## Deve abrir a mídia original antes de

- editar, recortar, remover fundo ou corrigir cor;
- gerar derivados;
- extrair paleta definitiva;
- identificar tipografia;
- preparar impressão;
- publicar em site, Instagram, cardápio ou anúncio;
- decidir capa/hero;
- avaliar fidelidade do produto;
- comparar morango e maracujá;
- redesenhar ou adaptar a logo;
- reutilizar ou substituir o QR.

## Regra de marca

O arquivo recebido como logo oficial traz o texto visual **cookLily**. O nome público registrado no projeto é **Lily Gourmet**.

Não substituir automaticamente `cookLily` por `Lily Gourmet`, nem recriar o lettering por conta própria. O arquivo original deve permanecer intacto e qualquer adaptação deve existir como derivado aprovado no kit de marca.

## Regra de produto

Os sabores das fotos foram informados pelo proprietário:

- creme/mousse amarelo: batida de açaí com maracujá;
- creme/mousse rosa: batida de açaí com morango.

Não inferir volume, peso, composição nutricional ou embalagem final só pela fotografia.

## Binário pendente

A foto de morango precisa ser reenviada com um nome único para preservar os bytes corretos no GitHub. Até lá, sua descrição visual pode ser usada para contexto, mas não há hash/arquivo binário canônico.

# Originais — Chefão

Esta pasta é reservada aos **10 JPEGs originais, sem edição**, do Chefão recebidos em 11/09/2026, caso ainda seja útil incorporá-los ao repositório.

Em 14/09/2026 o proprietário decidiu que esses binários **não são requisito para a consolidação atual**. A documentação e o catálogo podem permanecer válidos sem os JPEGs versionados.

Os nomes finais, dimensões e hashes esperados estão em `../README.md` e `../CATALOGO_IA.json`.

## Integridade

Se forem adicionados futuramente, os arquivos devem entrar sem abrir/regravar, converter, recomprimir ou alterar metadados. Após o upload, conferir o SHA-256 de cada JPEG contra o catálogo. Se qualquer hash divergir, tratar o arquivo como uma nova versão, não como o original documentado.

## Regra para agentes de IA

A presença de descrições no catálogo permite triagem sem abrir todos os arquivos. Entretanto, **para tarefas complexas ou visualmente sensíveis, a IA DEVE visualizar as imagens candidatas antes de utilizá-las**.

Não salvar edições nesta pasta. Derivados devem ficar em pasta própria e apontar para o original de origem.

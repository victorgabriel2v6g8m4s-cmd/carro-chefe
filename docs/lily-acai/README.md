# CookLily — operação temporária

## Nome público e compatibilidade técnica

O nome público definitivo da marca é **CookLily**. No ativo visual oficial, o wordmark aparece como **cookLily**.

Identificadores técnicos preservados por compatibilidade:

- branch lily-acai;
- documentação docs/lily-acai/;
- frontend apps/lily_acai/;
- URL pública /lilyacai/*;
- API /api/v1/lily/*;
- banco lily-acai.db.

## Escopo

A CookLily é uma operação temporária para geração de caixa antes da inauguração do Carro Chefe. Compartilha domínio, VPS e proxy por economia, mas mantém identidade, autenticação, banco, clientes, catálogo, pedidos, pagamentos, tracking e mídia logicamente separados.

A apresentação pública permanece **CookLily × Carro Chefe — parceria temporária**. A separação técnica deve ser tratada na política de privacidade/termos, não como destaque comercial.

O cardápio inicial foi fechado em 24/09/2026.

Fonte canônica:

**docs/lily-acai/produtos/CARDAPIO_INICIAL_DEFINITIVO.md**

Decisões centrais:

- categorias: Batidas de Açaí, LilyShakes e Doces em breve;
- LilyShake = nome próprio da antiga linha “Milk-shake de Gelato Caseiro”;
- tamanhos 300 e 500 ml;
- sabores, combinações, preços e adicionais definidos;
- LilyMix permite até 3 sabores compatíveis;
- busca, filtros e catálogo de rolagem incremental;
- landing mostra apenas destaques/ofertas;
- produto esgotado permanece visível;
- checkout online faz parte do lançamento comercial completo;
- margem líquida mínima de 10% como guardrail;
- Destaque da Semana escolhido com participação das redes sociais.
